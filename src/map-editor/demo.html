🗺️ Map Editor

Erstelle und bearbeite Level für das Blockly-Projekt

Gestartet mit: npm run editor

📋 Anleitung:

🎨 Visueller Editor (Linke Seite):

  • Objekt auswählen: Klicke auf ein Objekt in der Toolbar (Auto 🚗, Ziel 🏠, Wegpunkt ⭐, Hindernis ❌)
  • Platzieren: Klicke auf das Grid, um das ausgewählte Objekt zu platzieren
  • Vorschau: Bewege die Maus über das Grid, um eine Vorschau zu sehen
  • Abbrechen: Drücke ESC oder wähle ein anderes Objekt
  • Entfernen: Aktiviere den "Entfernen-Modus" und klicke auf Objekte
  • Exportieren: Speichere dein Level als JSON-Datei
  • Leeren: Entferne alle Objekte vom Level

📝 JSON View (Rechte Seite):

  • Live-Updates: Das JSON wird automatisch aktualisiert beim Platzieren von Objekten
  • Emojis ändern: Bearbeite die Emoji-Werte direkt im JSON
  • Waypoint-Reihenfolge: Ändere die Reihenfolge im Array für die Einsammel-Reihenfolge
  • Formatieren: Formatiert das JSON für bessere Lesbarkeit
  • Speichern: Validiert und übernimmt die JSON-Änderungen in den Editor

🎯 Objekt-Typen:

  • Auto (🚗): Das spielbare Auto
  • Ziel (🏠): Das Ziel
  • Wegpunkt (⭐): Wegpunkt zum Einsammeln
  • Hindernis (❌): Hindernis
